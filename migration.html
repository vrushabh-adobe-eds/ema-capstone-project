Executive Summary

Migration Phases & Sequencing

Ordered by dependency then page-count descending — biggest template ships first after foundations. Forms/interactive elements come late. Each phase is independently deployable and testable.

0Foundationssetup
Extract design tokens (brand colours, type scale, spacing) into styles/styles.css. Establish placeholders for dynamic values. Configure the DA asset path; re-host images.
1Global Elements — Header & Footerall pages
Instrument site-wide header + navigation and footer. Author the footer as a reusable fragment.
2Homepage1 page
Migrate the highest-fidelity page to validate the core block set (hero, carousel, cards) and design tokens.
3Adventure Detail — highest volume16 pages
Build the repeating detail template (title + metadata + gallery carousel) and bulk-import all 16 pages. Largest single win.
4Magazine Article5 pages
Second template cluster — article layout with rich text, images and pull-quotes.
5Listings & Content3 pages
Adventures listing (cards grid + tabs + search), Magazine listing, and the About page (columns/layout).
6FAQs1 page
Accordion-driven text page. Minimal block complexity.
7Cleanup & QAfinal
Redirect map for any deprecated URLs, wire the search index (helix-query.yaml), and a final performance + accessibility QA pass (Lighthouse 100, CWV in "good").
